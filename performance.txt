  关于 GPU 利用率

  nvidia-smi 报告的 GPU 利用率低（15-18%）是正常的——原因：
  - RTX 5070 Ti 对这个小 CNN 模型太快了，32 个位置的推理仅需 ~0.1ms
  - GPU 推理是"脉冲式"的：极短的高负载后等待 CPU Python 代码
  - nvidia-smi 的 1 秒采样周期捕捉不到这些微秒级脉冲
  - GPU 推理的实际占比在 MCTS 内部计时中约为 15-20%

  要进一步提高 GPU 利用率，需要将 MCTS 用 C++/CUDA 实现（消除 Python
  开销），这是一个更大的工程。当前优化已在 Python 框架内达到了接近最优的水平。
